# Portfolio - Manager Transformation Digitale 🚀

Ce projet est mon portfolio professionnel, conçu pour démontrer ma double compétence : la **vision stratégique business** et la **maîtrise des outils technologiques** modernes.



## 🎯 Objectifs du projet
- **Accessibilité :** Intégration de polices spécifiques (OpenDyslexic) et respect des contrastes WCAG.
- **Automatisation :** Synchronisation dynamique avec l'API GitHub pour présenter mes projets en temps réel.
- **Performance :** Utilisation de Vite pour un chargement instantané.
- **Internationalisation :** Support complet FR/EN via Vue-i18n.

## 🛠 Stack Technique
- **Framework :** [Vue.js 3](https://vuejs.org/) (Composition API)
- **Build Tool :** [Vite](https://vitejs.dev/)
- **Styling :** [Tailwind CSS v4](https://tailwindcss.com/) (Design responsive & accessible)
- **Routing :** Vue Router
- **i18n :** Vue-i18n (Multilingue)
- **Déploiement :** GitHub Actions (CI/CD)

## ✨ Fonctionnalités clés
- **Mode Lecture Inclusif :** Un bouton dédié permet de basculer sur une police adaptée aux profils dyslexiques.
- **Filtrage par Stack :** Un algorithme trie automatiquement mes dépôts GitHub par technologie utilisée.
- **Design "Warm & Trust" :** Palette de couleurs chaudes (Terracotta, Crème, Ocre) pour une expérience utilisateur rassurante et créative.
